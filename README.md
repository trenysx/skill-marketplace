# skill-marketplace

> **pnpm for skills — search, install, update skills from multiple sources.**

```bash
npx skill-marketplace search --mock
npx skill-marketplace search "linter"
npx skill-marketplace install anthropics/skills
```

Searches `topic:agent-skills` via GitHub API, fallback mock (4 skills, 168k-275k stars).
